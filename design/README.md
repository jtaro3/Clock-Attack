# Clock Attack デザインデータ

ゲームのキャラクターとアイテムに合わせたデザインを、編集できる SVG として保存しています。すべて背景は透明です。

| フォルダー | 内容 |
| --- | --- |
| `enemies/` | 体力1の青、体力2の緑、体力3の赤のスライム |
| `items/` | スライムが落とす青・緑・赤の時計 |
| `player.svg` | 上から見たプレイヤー。上向きが基準方向 |
| `sword.svg` | 攻撃用の剣 |
| `palette.json` | 色の指定値 |

各 SVG は 64×64 の座標で作成しています。現行ゲームは Canvas で近い形と同じ配色を描画しており、このフォルダーはデザインの編集・管理用です。SVG を編集しただけでは公開中のゲーム画面には自動反映されません。
