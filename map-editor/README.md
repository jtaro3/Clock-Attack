# 独立マップエディター

## 起動・画像追加

1. maps/tiles に縦横が32pxの倍数のPNGを追加します。
2. open-editor.cmd を実行します。画像一覧を再生成してエディターを開きます。
3. ファイル名がパレットに表示され、選択して描画できます。

index.htmlの直接起動では、前回生成した一覧を使います。画像の追加・削除・変更後はopen-editor.cmdを実行してください。HTTPサーバーは不要です。PNG形式や32pxの倍数でないサイズなら一覧の更新を止め、ファイル名をエラー表示します。

このフォルダ全体をコピーすれば別の場所でも使えます。

## 保存とゲームへの反映

「保存」はブラウザー内の保存です。「書き出し」でclock-attack-grassland.jsonを出力し、ゲームのmaps内の同名JSONを置き換えます。JSONは画像を含むため、追加チップの画像をゲームへ別途コピーする必要はありません。バランス調整用game-data.jsonには上書きしないでください。
公開時はdist/mapsにも同じJSONをコピーし、公開作業が必要です。

画像はファイル名で対応付けます。並び順が変わっても保存済みのマップは同じ画像へ読み替えます。使用中の画像を削除・改名すると読み込めなくなるため、書き出したJSONをバックアップしてください。旧4種類だけのマップJSONも読み込めます。

## 描画ツール

1・3・5・7マスを選べます。クリック位置を中央に直線状に塗ります。選択中の3・5・7マスを再度押すと横→縦→右下がり斜め→右上がり斜めの順で回転します。マップ外は塗りません。

## 台帳との関係

現時点ではパレットは画像フォルダから作ります。assets/map_tilesシートのenabledや当たり判定・耐久力はまだ連携していません。32pxを超える画像は、クリックしたマスを左上としてオブジェクト層に配置します。配置済みオブジェクトと重なる場所やマップ外には配置できません。当たり判定・耐久力はまだ未実装です。
