# 独立マップエディター

このフォルダだけを別の場所へコピーして使えます。ゲームのコードや画像への参照はありません。

## 起動

`index.html` をブラウザーで開いてください。ローカルHTTPサーバーは不要です。
「保存」はエディター内のブラウザー保存です。フォルダを移動すると保存データの扱いはブラウザーによって変わるため、移動前にJSONを書き出してください。

## ゲームへの反映

1. 「書き出し」で `clock-attack-grassland.json` をダウンロードします。
2. Clock-Attack の `maps/clock-attack-grassland.json` をそのファイルで手動で置き換えます。
3. ローカルプレビューでゲームを開き直します。ブラウザー内の古い編集データよりJSONを優先します。

公開用は同じJSONを `dist/maps/clock-attack-grassland.json` にもコピーしてから公開します。ファイルを置き換えただけでは公開サイトは更新されません。
`game-data.json` はバランス調整用です。マップJSONで上書きしないでください。

マップの形式は version=1、24列×18行、tilesは432個の整数（0:草、1:濃い草、2:花、3:土）です。不正なJSONや読み込み失敗時はゲームが標準マップで起動し、ブラウザーのコンソールに理由を表示します。

## ファイル

- index.html: 画面
- editor.js: 編集・保存・JSON入出力
- map-data.js: マップ形式・描画・エディター専用保存
- maps/grassland-tiles.png: チップ画像
## 描画ツール

1・3・5・7マスを選べます。選択した位置を中央として直線状に塗ります。選択中の3・5・7マスをもう一度押すと横→縦→右下がり斜め→右上がり斜め→横の順で回転します。マップの外側は塗りません。

## チップの大きさ

1マスは32×32px（ズーム100%時）。現在は1254×1254pxの画像を4区画に分け、各区画から213×213pxを切り出して32×32pxに縮小しています。元の切り出し幅の約15%です。個別チップ画像を作るなら32×32pxが基準ですが、個別画像を読み込む機能はまだありません。
